# nStorage

This is an implementation of a USB Storage Device on the TI-Nspire that allows file access directly in your computer's native filesystem. After exiting the program, make sure you click "Home" > "[2] Documents" to refresh the calculator's OS's filesystem to see you changes.

## Compatability

Currently tested on macOS 26 and a TI-Nspire CX, so add an issue with your combination and any issues you find. If there is a problem, try using the nStorage-debug.tns version with the operation that didn't work. That version generates a "usb_create_log.txt" log file in the main "/documents" folder once you exit the program, make sure to send that over.
