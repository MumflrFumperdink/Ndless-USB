# nStorageKbdMouse

This is an implementation of a USB Storage Device and a USB Mouse and Keyboard on the TI-Nspire. See the individual nStorage and nKbdMouse folders for more information (it is essentially a combination of the two). Note that during file transfers, mouse and keyboard updates might experience some lag.

## Compatability

Currently tested on macOS 26 and a TI-Nspire CX, so add an issue with your combination and any issues you find.
